**Role:** Instructor

**Course:** Introduction to Applied Statistics II (Winter 2026)

This undergraduate course covers fundamental concepts and methods in applied statistics, with an emphasis on statistical inference, regression modeling, analysis of variance, and the practical use of statistical software for data analysis. Students develop the skills to analyze real-world data, interpret statistical results, and communicate findings effectively.

## Topics

- Statistical inference
- Confidence intervals and hypothesis testing
- Linear regression
- Analysis of variance (ANOVA)
- Model diagnostics
- Applications using statistical software
